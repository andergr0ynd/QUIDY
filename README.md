# QUIDY

Демо без привязки к домену и без входа через Discord, Telegram или Twitch: [andergr0ynd.github.io/QUIDY](https://andergr0ynd.github.io/QUIDY/).

Кнопки на главной открывают пример личного кабинета. PHP, база и OAuth на GitHub Pages не выполняются.

`OAuth/config.php` с паролями и ключами в репозиторий не входит. Для локального запуска скопируйте `OAuth/config.example.php` в `OAuth/config.php`.
